# SessionRecap

## 0.2.0

- A minimap button opens the window. Drag it around the minimap; `/session button` hides it.
- Every login now says one line in chat: that counting has started, that the session is carrying on, or a summary of the last one.
- `/session debug` lists the money and loot events the game has sent this login, to explain a figure that stays at zero.
